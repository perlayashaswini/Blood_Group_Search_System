# LifeLink — Blood Group Search System

A responsive front-end prototype based on the uploaded Blood Group Search System project report.

## Run
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge, Firefox or Safari.
3. No installation or build step is required.

## Demo accounts
- Admin: `admin` / `admin123`
- Coordinator: `coord` / `coord123`
- Requester: `requester` / `req123`
- Donor: `donor` / `donor123`

## Included demo workflows
- Donor registration and profile management
- Search verified donors by blood group, city/location and availability
- Donor directory and availability updates
- Blood request creation and status tracking
- Role-based demo sign-in and coordinator/admin donor verification
- Notifications and read status
- Reports, blood-group distribution, JSON backup and restore

## Important limitations
This is a browser-only prototype. It uses localStorage and demo credentials; it is not secure authentication or a production backend. Do not enter real personal or medical data or use it to coordinate actual transfusions. Donor eligibility and blood compatibility must be confirmed by qualified healthcare professionals and licensed blood banks. A production system requires a secure server, database, password hashing, server-side access controls, HTTPS, audit logging, backups and privacy/security review.

The medical-themed hero photograph and Google Fonts load from external services and require internet access.
